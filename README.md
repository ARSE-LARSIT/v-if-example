### Detalhe

Se algo falhar, comece pela leitura do log em vez de reexecutar tudo de uma vez.

Deixando claro desde o começo: este repositório apenas reúne anotações de um curso gratuito, cujo material não pode ser redistribuído por mim. Se o tema interessar, procure o curso aberto da trilha de Java com Spring Boot. Se a plataforma encerrar o acesso ou passar a cobrar pelo conteúdo, isso foge do meu controle — mas o material de lá é excelente e quem assina um plano consegue acesso bem mais amplo.
